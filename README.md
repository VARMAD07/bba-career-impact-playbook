# The BBA Career & Impact Playbook

A practical, reusable field guide for BBA students, presented in Mohammad Hammad Faridi's name.

## Live site

https://varmad07.github.io/bba-career-impact-playbook/

## What it covers

- BBA career tracks and specialisations
- Academic planning and skill development
- Portfolio projects and supervised experience
- Internships and application preparation
- Scholarships, funding and award comparison
- MBA, MiM and specialist master's decisions
- Optional UN, NGO and international-development pathways

## Editorial note

This is a reference guide, not a personal achievement record. Examples are learning exercises unless explicitly stated otherwise. Opportunity rules, eligibility and funding information should be checked against the linked official sources before applying.
